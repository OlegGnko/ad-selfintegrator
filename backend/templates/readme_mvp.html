§2 — Jak zaimportować konfigurację
Import nadpisuje istniejące etapy lejka i listy słownikowe. Wykonaj go na świeżym (nowym) portalu lub przed dodaniem jakichkolwiek danych produkcyjnych.
  1. Zaloguj się do portalu Bitrix24 jako Administrator.
  2. Przejdź do Ustawienia (ikona koła zębatego w lewym pasku) → CRM → Import ustawień CRM.
    Alternatywnie: menu górne → CRM → Ustawienia → Import.
  3. Kliknij Wybierz plik i wskaż plik MVP_Config_*.zip.
  4. Kliknij Importuj. Poczekaj na komunikat o zakończeniu (kilka sekund).
  5. Sprawdź wyniki: CRM → Ustawienia → Etapy lejka (powinna pojawić się skonfigurowana lista etapów).
  6. Sprawdź źródła: CRM → Ustawienia → Źródła.
  7. Sprawdź pola: CRM → Ustawienia → Pola użytkownika → Leady / Oferty.
